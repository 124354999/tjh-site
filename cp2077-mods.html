CYBERPUNK 2077 · MODDING

把模组装进去不崩
——一份能照着做的顺序

不是为了教谁，是给自己记一遍：这套东西每次重装都要重新捋，写下来省事。

一、先分清三类文件

下回来的模组，看着五花八门，其实只有三种东西：

类型长什么样放哪
资源存档.archive / .archive.xlarchive\pc\mod\
脚本.redsr6\scripts\
插件 / 配置.dll、.toml、.ini看压缩包里的目录结构，原样复制

判断方法很简单：解压后看它有没有自带 archive、r6、bin 这些目录。有就整个目录盖进游戏根目录，没有就按上表自己放。

二、前置框架，顺序不能乱

大部分模组都依赖框架。我用的这套，按依赖顺序装：

  1. RED4ext —— 最底层，负责加载其他插件
  2. CET（Cyber Engine Tweaks）—— 控制台和界面
  3. redscript —— 红色脚本编译器
  4. ArchiveXL —— 扩展的资源加载
  5. TweakXL —— 参数覆盖
  6. Codeware —— 很多模组的公共库
  7. Mod Settings —— 模组设置面板
游戏版本一变，框架全部要跟着换。2.0 时代的模组直接丢进 2.5，最常见的结果就是开游戏闪退。 装之前先确认模组页面上写的支持版本。

三、我踩过的坑

1. 启动器崩在显卡驱动里

REDlauncher.exe 在 AMD 驱动里报 c0000005，双击进不去游戏。绕过方法是直接从 Steam 启动，或者给快捷方式加参数：

Cyberpunk2077.exe --launcher-skip

2. 开了两个游戏实例

先点 Steam 的启动，又直接双击了 exe，结果 RED4ext 报日志文件被占用（permission denied）。先把所有游戏进程结束，再启动一次就行。

3. 语言变成英文

直接跑 exe 会丢掉 Steam 的语言参数。用 Steam 启动，或者在启动参数里补上：

--launcher-skip -language=schinese

4. 老模组集体不兼容

换大版本之后，先只装框架，进游戏确认能进，再一个一个加。全装完再排查，根本不知道是谁的问题。

四、装之前先备份

两件事分开做：

  • 存档：%USERPROFILE%\Saved Games\CD Projekt Red\Cyberpunk 2077
  • 模组目录：archive\pc\mod、r6\scripts、bin\x64\plugins

出问题就整个目录换回去，比一个个删快得多。

五、用脚本批量装

一个个拖太慢，我写了个 PowerShell 脚本，把压缩包全丢进一个文件夹，它自己解压、识别目录、复制到位、记日志：

.\install-mod.cmd          # 扫描并安装
.\install-mod.cmd -Test    # 只看会复制什么，不动手

脚本核心就三件事：解压到临时目录 → 找 archive / r6 / bin 这些顶层目录 → robocopy 覆盖过去。日志写在单独的目录里，出问题能倒查。

这套流程的前提是「一次只改一件事」。同时装五个模组再排查，等于给自己加难度。

六、目录长什么样

装好框架之后，游戏根目录里和模组有关的部分是这样：

Cyberpunk 2077\
├─ archive\pc\mod\           ← 所有 .archive / .archive.xl 放这儿
├─ r6\scripts\               ← .reds 脚本
├─ r6\tweaks\                ← .toml 参数覆盖
├─ bin\x64\plugins\          ← RED4ext 插件（.dll）
│  └─ cyber_engine_tweaks\   ← CET 本体 + mods 子目录
│     ├─ bindings.json       ← 控制台热键
│     └─ mods\               ← CET 模组（Lua）
└─ red4ext\plugins\          ← RED4ext 扩展插件

想知道某个模组到底装没装上，看这三个地方就行：archive\pc\mod 有没有它的 .archive、r6\scripts 有没有 .reds、bin\x64\plugins 有没有对应 dll。

七、报错对照表

这几个是我真遇到过的，照着查能省不少时间：

现象原因怎么办
启动器闪退，事件查看器里是 atio6axx.dll / c0000005 AMD 驱动和 REDlauncher 冲突 加 --launcher-skip 直接从游戏本体启动
Unable to rotate the log file ... permission denied 开了两个游戏实例，RED4ext 抢日志文件 任务管理器结束所有游戏进程，再启动一次
界面全变英文 直接跑 exe 丢了 Steam 的语言参数 补 -language=schinese，或用 Steam 启动
进游戏就崩，没有任何报错 模组和当前版本不兼容（最常见） 先把 archive\pc\mod 里的东西全移走，只留框架，确认能进再逐个加回
CET 控制台按 ~ 打不开 bindings.json 里的热键值失效 把 cet.overlay_key 改成一个有效的键码（比如 192 是反引号）

八、脚本下载

这套流程我写成了脚本，省得一个个拖文件。把压缩包丢进一个文件夹，双击运行即可：

  • install-mod.cmd —— 双击入口
  • install-mod.ps1 —— 实际干活的部分

它做的事：解压到临时目录 → 识别 archive / r6 / bin / red4ext 这些顶层目录 → 复制到游戏根目录 → 备份被覆盖的同名文件 → 写日志。
